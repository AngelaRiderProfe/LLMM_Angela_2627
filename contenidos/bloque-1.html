Bloque 1

Estructura y sintaxis

Este bloque es la base de todo lo demás: cómo se escribe un elemento, cómo se le añaden atributos y cuál es el esqueleto obligatorio de cualquier página.

1.1 Anatomía de un elemento

  • Etiqueta: la marca en sí, <a> o </a>.
  • Elemento: todo el conjunto, desde la apertura hasta el cierre, incluido el contenido.
  • Atributo: información extra que se escribe siempre en la etiqueta de apertura, con la forma nombre="valor".

Elementos vacíos. Algunos elementos no tienen contenido y por tanto no tienen etiqueta de cierre: <br>, <hr>, <img>, <meta>, <link>, <input>. En HTML5 se escriben <br>; la forma <br /> (heredada de XHTML) también es válida.

1.2 Reglas de sintaxis

  1. Anidamiento correcto: lo último que se abre es lo primero que se cierra.
  1. Minúsculas: HTML no distingue mayúsculas, pero la guía de estilo (y XHTML) exige minúsculas.
  2. Comillas dobles en los valores de atributos, siempre.
  3. Atributos booleanos: basta con escribir el nombre (<input required>). En XHTML se escribe required="required".
  4. Espacios en blanco: el navegador junta varios espacios y saltos de línea en uno solo. Usa la sangría (2 espacios) para que el código sea legible, no para dar formato a la página.

1.3 El esqueleto de un documento HTML5

El documento forma un árbol: html es la raíz y tiene dos hijos, head y body. Este árbol es lo que después manipularemos con JavaScript (el DOM).

Elemento Para qué sirve Atributos importantes ¿Obligatorio?
<!DOCTYPE html> Indica que el documento es HTML5. No es una etiqueta, es una declaración — Sí, primera línea
<html> Elemento raíz: contiene todo lo demás lang (idioma: es, en, ca…) Sí
<head> Información sobre la página (metadatos). No se muestra — Sí
<meta> Metadatos concretos charset, name + content charset sí
<title> Título de la pestaña, de los favoritos y de los resultados de Google — Sí (el validador da error sin él)
<link> Enlaza recursos externos: CSS, favicon rel, href No
<style> CSS dentro de la página — No
<script> Código JavaScript src, defer No
<body> Todo el contenido visible — Sí

1.4 Las etiquetas meta más usadas

Código Qué hace
<meta charset="UTF-8"> Codificación de caracteres. Sin ella, las tildes y la ñ pueden verse mal. Debe ir la primera dentro de head
<meta name="viewport" content="width=device-width, initial-scale=1.0"> Hace que la página se adapte al ancho del móvil
<meta name="description" content="…"> Resumen de la página que muestran los buscadores
<meta name="author" content="…"> Autor del documento
<meta name="keywords" content="…"> Palabras clave (hoy los buscadores casi no las usan)

1.5 Atributos globales

Se pueden usar en cualquier elemento del body:

Atributo Para qué sirve Ejemplo
id Identificador único en la página <section id="contacto">
class Una o varias clases para agrupar elementos y darles estilo <p class="aviso importante">
style CSS en línea <p style="color: red;">
title Texto que aparece al pasar el ratón <abbr title="Formación Profesional">FP</abbr>
lang Idioma de ese fragmento <p lang="en">Hello</p>
hidden Oculta el elemento <p hidden>No se ve</p>
data-* Datos propios para JavaScript <li data-precio="20">

1.6 Comentarios

Sirven para documentar el código y para «desactivar» temporalmente un trozo. Ojo: se ven con Ctrl+U, así que nunca escribas contraseñas ni datos privados en ellos.

1.7 Errores típicos

  • Olvidar el <title>: el validador da error.
  • Poner contenido visible dentro de <head>.
  • Cerrar en el orden equivocado (ver 1.2).
  • Usar comillas tipográficas (“ ”) copiadas de Word en lugar de comillas rectas (").
  • Escribir el atributo en la etiqueta de cierre: </a href="…">.
