Bloque 4

Enlaces, rutas, imágenes y multimedia

Los enlaces son la «H» de HTML (HyperText): permiten saltar de un documento a otro. Para que funcionen, y para que funcionen las imágenes, hay que dominar las rutas.

4.1 Rutas de archivos

Una ruta indica dónde está un archivo. Partimos de esta estructura:

Tipo Ejemplo desde ciclos/dam.html Significado
Relativa, misma carpeta otro.html Archivo junto al actual
Relativa, subcarpeta fotos/aula.jpg Entra en la carpeta fotos
Relativa, carpeta padre ../index.html .. sube un nivel
Relativa, padre + otra carpeta ../img/logo.png Sube y entra en img
Relativa a la raíz del sitio /img/logo.png Desde la raíz del servidor (con Live Server funciona; abriendo el archivo con doble clic, no)
Absoluta https://www.w3.org/logo.png Dirección completa en Internet

Regla práctica: dentro de tu sitio usa rutas relativas, así la carpeta funciona aunque la muevas o la subas a un servidor. Evita espacios, tildes y mayúsculas en nombres de archivos: en servidores Linux Logo.png y logo.png son archivos distintos.

4.2 Enlaces: <a>

Atributo Para qué sirve Ejemplo
href Destino del enlace (obligatorio para que sea enlace) href="dam.html"
target Dónde se abre. _self (por defecto, misma pestaña) o _blank (pestaña nueva) target="_blank"
rel Relación con el destino. Con _blank se recomienda noopener por seguridad rel="noopener"
title Texto de ayuda al pasar el ratón title="Abre la web oficial"
download Descarga el archivo en lugar de abrirlo download="apuntes.pdf"

Tipos de destino:

El texto del enlace debe decir a dónde lleva: «Descargar el calendario», nunca «pincha aquí» (un lector de pantalla puede leer solo la lista de enlaces).

4.3 Imágenes: <img>

Atributo Para qué sirve ¿Obligatorio?
src Ruta de la imagen Sí
alt Texto alternativo: se lee si la imagen no carga o con lector de pantalla. Describe lo que aporta la imagen; si es decorativa, alt="" Sí (el validador da error)
width / height Tamaño en píxeles. Ponerlos evita que la página «salte» mientras carga Recomendado
title Texto al pasar el ratón No
loading lazy: no la carga hasta que el usuario se acerca a ella No

Formatos: JPG para fotos, PNG para imágenes con transparencia o texto, SVG para logos e iconos (vectorial, no pierde calidad), WebP para fotos más ligeras, GIF para animaciones sencillas.

Imagen con pie de foto: figure agrupa un contenido ilustrativo y figcaption es su leyenda.

Imágenes adaptables: <picture> permite dar distintas versiones según el ancho de pantalla.

Mapas de imagen (<map> + <area>) permiten zonas clicables dentro de una imagen; hoy se usan poco.

4.4 Favicon

Es el icono de la pestaña. Se enlaza en el head:

Usa una imagen cuadrada (32×32 o 48×48 píxeles). Si no cambia, borra la caché del navegador (Ctrl+F5).

4.5 Vídeo y audio

Se ponen varios <source> para que el navegador use el primer formato que entienda; el texto final solo se ve si no entiende ninguno.

Atributo video audio Para qué sirve
controls Sí Sí Muestra los botones de reproducir, volumen…
autoplay Sí Sí Empieza solo. Los navegadores lo bloquean salvo con muted
muted Sí Sí Sin sonido
loop Sí Sí Se repite
poster Sí No Imagen antes de reproducir
width / height Sí No Tamaño

Formatos: vídeo MP4 (H.264) y WebM; audio MP3, OGG y WAV.

4.6 Contenido incrustado: <iframe>

Un iframe muestra otra página web dentro de la tuya. Es como YouTube o Google Maps permiten insertar su contenido (botón Compartir › Insertar).

Atributo Para qué sirve
src URL de la página que se incrusta
width / height Tamaño del marco
title Descripción para accesibilidad (el validador lo recomienda)
name Nombre del marco: un enlace con target="nombre" se abre dentro de él
allowfullscreen Permite pantalla completa
loading="lazy" Carga diferida

YouTube usa la URL /embed/ID, no la normal /watch?v=ID. Muchas webs prohíben ser incrustadas: si sale en blanco, no es tu error.

4.7 Errores típicos

  • src="C:\Users\Ana\Escritorio\foto.jpg": ruta de tu ordenador que no funcionará en ningún otro.
  • Olvidar alt en una imagen.
  • Barras invertidas (img\logo.png): en la web siempre /.
  • Ancla sin #: href="horario" busca un archivo llamado horario.
  • target="blank" sin guion bajo: crea una pestaña llamada blank.

Ejercicios del bloque 4

E14 Rutas en papel

  1. Copia el árbol de 4.1 en una hoja.
  2. Escribe la ruta relativa para ir: de index.html a logo.png; de dam.html a index.html; de dam.html a estilos.css; de contacto.html a dam.html; de dam.html a una web externa.
  3. Crea esa estructura en ejercicios/e14/ y comprueba cada ruta con un enlace real.

E15 Mini-sitio de 3 páginas

  1. En ejercicios/e15/ crea index.html, ciclos.html y contacto.html.
  2. Pon en las tres el mismo menú con enlaces a las tres páginas.
  3. En ciclos.html crea tres secciones con id y un índice al principio con enlaces internos (#). Añade al final un enlace «Volver arriba».
  4. Añade un enlace externo que se abra en pestaña nueva con rel="noopener", un mailto: con asunto y un tel:.

E16 Galería

  1. Crea img/ dentro de e15 y añade 3 imágenes (con licencia libre: Pixabay, Unsplash, Wikimedia).
  2. Crea galeria.html con las tres imágenes dentro de figure + figcaption, todas con alt descriptivo, width y height.
  3. Haz que el logotipo de la cabecera sea un enlace a index.html.
  4. Añade un favicon a las cuatro páginas.

E17 Multimedia

  1. Crea multimedia.html con un video (controls, poster, dos source) y un audio.
  2. Inserta un vídeo de YouTube y un mapa de Google Maps de tu instituto con iframe (copia el código de Compartir › Insertar y añádele title).
  3. Prueba autoplay con y sin muted y explica en un comentario qué ocurre.
