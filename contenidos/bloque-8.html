Bloque 8

Ampliación: gráficos y primer JavaScript

Este bloque es opcional y sirve de puente con las siguientes unidades: SVG es XML (UT4) y el JavaScript que manipula elementos es el DOM (UT5).

8.1 SVG: gráficos vectoriales

SVG (Scalable Vector Graphics) describe dibujos con etiquetas. Al ser vectorial, se amplía sin perder calidad. Se puede usar como archivo (<img src="logo.svg">) o escribir directamente en el HTML:

Elemento Dibuja Atributos principales
rect Rectángulo x, y, width, height, rx (esquinas redondeadas)
circle Círculo cx, cy (centro), r (radio)
ellipse Elipse cx, cy, rx, ry
line Línea x1, y1, x2, y2
polygon Polígono points="x,y x,y …"
text Texto x, y, font-size
(comunes) — fill (relleno), stroke (borde), stroke-width

Fíjate en que todos los elementos se cierran con /> y llevan el espacio de nombres xmlns: es XML.

8.2 Canvas

<canvas> es un lienzo vacío en el que se dibuja con JavaScript, píxel a píxel. Se usa para juegos y gráficos animados.

SVG Canvas
Tipo Vectorial, con etiquetas Mapa de píxeles, con JavaScript
¿Se amplía sin perder calidad? Sí No
Cada forma es un elemento del DOM Sí (se le puede dar estilo y eventos) No
Ideal para Logos, iconos, mapas, gráficos Juegos, animaciones, edición de imágenes

Ejercicios del bloque 8

E29 Logo en SVG

Dibuja en SVG el logotipo de tu proyecto usando al menos un rect, un circle, un polygon y un text. Ábrelo también como archivo logo.svg independiente y úsalo como favicon.

E30 Mi primer botón

  1. Crea un párrafo con id y tres botones: uno cambia el texto, otro el color y otro oculta el párrafo (p.hidden = true).
  2. Añade un input type="range" con oninput que muestre su valor en un <output>.
