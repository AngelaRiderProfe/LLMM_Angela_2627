Lo que ve el navegador

Trabaja la guía en orden: cada bloque se apoya en el anterior y los ejercicios amplían siempre la misma carpeta de proyecto. En cada elemento encontrarás cuatro apartados fijos:

  • Para qué sirve: el significado del elemento, no solo su aspecto.
  • Sintaxis y atributos: cómo se escribe y qué atributos admite.
  • Ejemplo comentado: código para copiar, probar y modificar.
  • Errores típicos: lo que el validador suele marcar.

Al final de cada bloque hay ejercicios guiados (E00, E01…). Un ejercicio solo está terminado cuando pasa el validador W3C sin errores.

Preparar el entorno (una sola vez)

  1. Instala Visual Studio Code desde code.visualstudio.com.
  2. En VS Code abre la pestaña Extensiones (Ctrl+Shift+X) e instala Live Server (Ritwick Dey). Opcionalmente, HTMLHint para ver errores mientras escribes.
  3. Crea esta estructura de carpetas en tu equipo o en tu repositorio:
  1. En VS Code usa Archivo › Abrir carpeta y elige ut2-html. Trabaja siempre con la carpeta abierta, no con archivos sueltos: así las rutas funcionan.
  2. Para ver una página, clic derecho sobre el .html › Open with Live Server. Cada vez que guardes (Ctrl+S) el navegador se recarga solo.
  3. Para validar: entra en validator.w3.org, pestaña Validate by Direct Input, pega el código y pulsa Check.

Herramientas del navegador (DevTools)

Pulsa F12 o clic derecho › Inspeccionar. En la pestaña Elements ves el árbol de etiquetas tal como lo entiende el navegador; si pasas el ratón por una etiqueta, se resalta en la página. Con Ctrl+U ves el código fuente tal como lo escribiste. Comparar ambos es la mejor forma de encontrar etiquetas mal cerradas.
