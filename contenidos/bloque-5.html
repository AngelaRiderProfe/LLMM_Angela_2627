Listas y tablas

Listas y tablas organizan información con estructura: las listas, elementos en serie; las tablas, datos en filas y columnas. Las tablas solo son para datos tabulares, nunca para maquetar la página (eso se hacía antes de CSS y hoy es un error).

5.1 Lista no ordenada: <ul>

Para elementos cuyo orden no importa. Cada elemento va en un <li> (list item).

La viñeta se cambia con CSS: list-style-type: square; (disc, circle, square, none).

5.2 Lista ordenada: <ol>

Para pasos o rankings donde el orden sí importa.

Atributo Para qué sirve Ejemplo
type Tipo de numeración: 1, A, a, I, i type="I" → I, II, III
start Número inicial start="5"
reversed Cuenta hacia atrás <ol reversed>
value (en li) Fuerza el número de ese elemento <li value="10">

5.3 Lista de descripción: <dl>

Para pares término–definición: glosarios, fichas técnicas, preguntas frecuentes.

Elemento Significado
dl Description list, el contenedor
dt Description term, el término
dd Description details, la descripción (puede haber varias por término)

5.4 Listas anidadas

Una lista puede ir dentro de un li, nunca directamente dentro de otro ul. Así se hacen los menús con submenús.

5.5 Tablas: estructura básica

Elemento Significado Qué contiene
table La tabla Filas o grupos de filas
tr Table row, una fila Celdas
th Table header, celda de encabezado (negrita y centrada por defecto) Texto u otros elementos
td Table data, celda de datos Texto u otros elementos
caption Título de la tabla; va justo después de <table> Texto

La tabla se construye fila a fila: no hay elemento «columna»; las columnas salen de colocar las celdas en el mismo orden en cada fila.

5.6 Tablas: secciones y accesibilidad

Elemento / atributo Para qué sirve
thead Agrupa las filas de encabezado
tbody Agrupa las filas de datos (puede haber varios)
tfoot Agrupa las filas de pie: totales, notas
scope="col" / scope="row" Indica si un th es encabezado de columna o de fila (lo usan los lectores de pantalla)
colgroup + col Permite dar estilo a columnas enteras: <col span="2" style="background: #eee">

5.7 Combinar celdas: colspan y rowspan

  • colspan="n": la celda ocupa n columnas hacia la derecha. En esa fila escribes n–1 celdas menos.
  • rowspan="n": la celda ocupa n filas hacia abajo. En las n–1 filas siguientes escribes una celda menos.

Truco: antes de escribir una tabla con celdas combinadas, dibújala en papel con una cuadrícula y cuenta cuántas celdas hay realmente en cada fila.

Para ver los bordes mientras practicas, añade en el <style>: table, th, td { border: 1px solid black; border-collapse: collapse; }. El atributo border="1" de <table> es antiguo: el validador lo marca como obsoleto.

5.8 Errores típicos

  • Texto suelto dentro de <ul> sin <li>.
  • Lista anidada fuera del <li>.
  • Filas con distinto número de celdas (la tabla se descuadra).
  • Olvidar quitar las celdas que «ocupa» un rowspan.
  • Usar tablas para colocar menús o columnas de la página.

Ejercicios del bloque 5

E18 Receta

  1. En e18-receta.html escribe una receta con un h1 y dos h2: «Ingredientes» y «Preparación».
  2. Ingredientes en ul; pasos en ol.
  3. Añade un apartado «Variantes» con una ol que empiece en 1 y use type="a".
  4. Añade un glosario de tres términos de cocina con dl.
  5. Crea un menú de navegación con una lista anidada (Recetas › Primeros, Segundos, Postres).

E19 Tu horario

  1. Dibuja en papel tu horario semanal real.
  2. Pásalo a e19-horario.html con caption, thead, tbody y tfoot.
  3. Los módulos de 2 horas seguidas van con rowspan y el recreo con colspan.
  4. Usa th con scope="col" para los días y scope="row" para las horas.
  5. Añade bordes con CSS y valida.

E20 Reto: copia la tabla

Tu profesor te dará una captura de una tabla con varias celdas combinadas en filas y columnas. Reprodúcela exactamente y valida.
