Qué es HTML

HTML (HyperText Markup Language) es un lenguaje de marcas: no es un lenguaje de programación, porque no tiene variables, condiciones ni bucles. Su función es describir la estructura y el significado del contenido de una página web (esto es un título, esto un párrafo, esto un enlace). El aspecto visual lo decide CSS y el comportamiento, JavaScript.

0.1 Marcas, etiquetas y el navegador

Una marca es un texto especial que rodea al contenido para decir qué es. En HTML las marcas se escriben entre < y >:

El navegador (Chrome, Firefox, Edge…) lee ese texto, interpreta las marcas y construye la página. Las marcas no se ven: se ve su efecto. Por eso un archivo HTML es simplemente texto plano con extensión .html y puede escribirse con cualquier editor.

0.3 Versiones y estándares

HTML ha cambiado mucho desde su creación. Conocer las versiones sirve para entender código antiguo y saber por qué hoy se escribe de una forma concreta.

Año Versión Organismo Qué aportó
1991 HTML (Tim Berners-Lee, CERN) — Primer lenguaje de la web: títulos, párrafos, enlaces
1995 HTML 2.0 IETF Primer estándar oficial; formularios
1997 HTML 3.2 W3C Tablas, applets; etiquetas de presentación (font, center)
1999 HTML 4.01 W3C Separa contenido (HTML) y estilo (CSS)
2000 XHTML 1.0 W3C HTML reescrito con las reglas estrictas de XML
2014 HTML5 W3C / WHATWG Etiquetas semánticas, vídeo y audio nativos, nuevos formularios, APIs
Desde 2019 HTML Living Standard WHATWG Estándar único que se actualiza de forma continua; ya no hay «HTML6»

Quién es quién: el W3C (World Wide Web Consortium) define muchos estándares web y mantiene el validador; el WHATWG, formado por los fabricantes de navegadores, mantiene hoy la especificación de HTML.

Ejercicios del bloque 0

E00 Hola mundo

  1. Dentro de ejercicios/ crea el archivo e00-hola.html.
  2. Escribe solo esta línea: <h1>Hola mundo</h1> y ábrelo con Live Server.
  3. Añade debajo <p>Mi primera página</p>, guarda y comprueba que se recarga.
  4. Pulsa Ctrl+U y luego F12. Escribe en un comentario qué diferencia ves entre ambos (pista: el navegador ha añadido html, head y body él solo).

E01 ¿Qué versión es?

  1. Tu profesor te dará tres fragmentos de código antiguo.
  2. Para cada uno, identifica la versión de HTML por su DOCTYPE y por las etiquetas que usa (por ejemplo, <font> indica HTML 3.2/4).
  3. Ordénalos en la línea temporal de 0.3 y explica en dos líneas qué cambiarías para pasarlos a HTML5.
