Bloque 3

Primer contacto con los estilos

HTML dice qué es cada cosa; CSS (Cascading Style Sheets, hojas de estilo en cascada) dice cómo se ve. Aquí solo aprenderemos a conectar CSS con HTML y a usar class e id; CSS se estudia a fondo en la UT3.

3.1 Cómo es una regla CSS

Propiedad Qué cambia Ejemplo de valor
color Color del texto red, #ff0000, rgb(255, 0, 0)
background-color Color de fondo lightyellow
font-family Tipo de letra Arial, sans-serif
font-size Tamaño de letra 16px, 1.2em
text-align Alineación left, center, right, justify
border Borde 1px solid black
padding / margin Espacio interior / exterior 10px

3.2 Colores

Un mismo color se puede escribir de varias formas:

Forma Ejemplo (rojo tomate) Explicación
Nombre tomato 140 nombres predefinidos
Hexadecimal #ff6347 Rojo, verde y azul de 00 a ff
RGB rgb(255, 99, 71) Cada canal de 0 a 255
RGBA rgba(255, 99, 71, 0.5) Igual + transparencia de 0 a 1
HSL hsl(9, 100%, 64%) Tono (0–360°), saturación y luminosidad

3.3 Tres formas de añadir CSS

1. En línea, con el atributo global style. Solo afecta a ese elemento.

2. Interna, con el elemento <style> dentro del head. Afecta a toda la página.

3. Externa, con un archivo .css y el elemento <link> en el head. Afecta a todas las páginas que lo enlacen.

Atributo de <link> Para qué sirve
rel Relación con el documento: stylesheet (hoja de estilos), icon (favicon)
href Ruta del archivo
media Opcional: solo para un tipo de dispositivo (print, screen)

¿Cuál usar? La externa, porque separa contenido y presentación: cambias un archivo y cambia todo el sitio, y el navegador lo guarda en caché. Si se aplican varias a la vez, gana la más cercana al elemento: en línea > interna > externa (de ahí lo de «cascada»).

3.4 class e id

Sirven para «poner nombre» a elementos y poder seleccionarlos desde CSS y JavaScript.

class id
¿Se puede repetir? Sí, en muchos elementos No, único en la página
¿Varios por elemento? Sí: class="aviso grande" No, uno solo
Selector CSS .aviso { } #cabecera { }
JavaScript getElementsByClassName("aviso") getElementById("cabecera")
Otro uso — Destino de enlaces internos: href="#cabecera"

Nombres: empiezan por letra, sin espacios ni tildes; usa guiones (aviso-principal). Pon nombres que digan qué es (aviso), no cómo se ve (rojo).

3.5 Errores típicos

  • Repetir el mismo id en dos elementos (el validador lo marca como error).
  • Escribir class=".destacado": el punto va en el CSS, no en el HTML.
  • Ruta de href incorrecta en <link>: la página se ve sin estilos y no da error visible. Mira la pestaña Consola de DevTools.
  • Olvidar el ; entre propiedades en el atributo style.

Ejercicios del bloque 3

E11 Estilo en línea

  1. Copia tu biografía (E06) como e11-estilos.html.
  2. Con el atributo style, cambia el color del h1 usando un nombre, el de los h2 usando hexadecimal y el fondo de un párrafo usando rgba con transparencia.
  3. Centra el h1 y cambia el tipo de letra de los párrafos.

E12 De línea a interna y a externa

  1. Elimina todos los atributos style y lleva esas reglas a un <style> en el head. Comprueba que la página se ve igual.
  2. Crea css/e12.css, mueve allí las reglas y enlázalo con <link>. Comprueba de nuevo.
  3. Crea una segunda página que enlace la misma hoja y observa que hereda el estilo.
  4. Completa en un comentario una tabla con ventajas e inconvenientes de las tres formas.

E13 Clases e id

  1. Crea la clase .destacado y aplícala a tres párrafos.
  2. Crea un aviso único con id="aviso-principal" y dale un estilo diferente.
  3. Aplica a un párrafo dos clases a la vez (destacado y otra nueva).
  4. Repite a propósito el id en otro elemento, valida y anota el error. Después corrígelo.
